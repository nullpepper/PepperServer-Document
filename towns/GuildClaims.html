联盟领地 ​

联盟领地是联盟的公共领地，大家一起建设生产设施（刷怪塔、农场、市场），权限按联盟职位分享。

由服务器自研插件 PepperClaim 提供。个人专属的家园领地见个人领地。

快速认识 /gclaim ​

指令作用
/gclaim create <名字>按当前选区创建联盟领地（先金锄框地）
/gclaim list [页数]本盟领地列表
/gclaim tp [领地]传送到本盟领地（不填传送到枢纽）
/gclaim map周边领地地图
/gclaim info [领地]查看联盟领地详情
/gclaim resize <领地>扩边/缩地（先 expand / 金锄框好）
/gclaim set welcome <领地> <消息>联盟领地进出消息（同家园）
/gclaim set preset <领地> 半开放联盟领地档位
/gclaim settp设置联盟领地传送点
/gclaim buy <块数>用公会金库买联盟额度
/gclaim quota联盟额度与槽位概览
/gclaim gui联盟领地图形界面

创建联盟领地 ​

  1. 拿金锄左键点一个角（pos1），走到对角右键点另一个角（pos2）。
  2. 确认粒子轮廓为绿色（合法），输入：
/gclaim create 联盟驻地

圈地规则与个人领地一致：不能重叠、出生点 100 格内禁圈、主城禁圈；另外联盟领地之间需保持 8 格间距。

槽位与子领地 ​

  • 联盟能开几块领地由槽位决定：初始 3 块，可通过繁荣度提升/购买扩展槽增加（至多 6 块）。
  • 每块联盟领地内可划分子领地（功能分区，无属主，全盟共享权限），最多 10 个：
/gclaim sub create 商店区

职位权限 ​

联盟领地内能做什么，由联盟职位决定：

/gclaim perms <领地>                  # 查看职位权限
/gclaim perm <领地> <职位> <旗标> <值> # 给某职位开某旗标（如 build ALLOW）

常用旗标与取值见个人领地，完整职位体系见职位与权限。

繁荣度与领地之心 ​

  • 成员在联盟领地内活动（生产、狩猎、驻留）会涨联盟活跃度（不能买），详见繁荣度与活跃度。
  • /gclaim prosperity 查看繁荣度详情；/gclaim top 查看活跃榜。

领地之心：把满级信标注册为联盟灯塔，解锁传送与特效：

指令作用
/gclaim heart register把脚下满级信标注册为领地之心
/gclaim heart unregister注销领地之心
/gclaim heart effect查看/切换信标特效
/gclaim heart info查看领地之心信息
/gclaim heart public on/off开关公开传送（银锭档位以上）

额度与经济 ​

联盟额度用联盟金库购买：

指令作用
/gclaim quota查看联盟额度与槽位
/gclaim buy <块数>用公会金库购买联盟额度
/gclaim worldslot <世界>购买世界专用扩展槽

联盟金库存取见联盟。

保护机制 ​

联盟领地享受与个人领地相同的保护：

  • 死亡掉落锁定：领地内死亡掉落物 60 秒内仅本人可拾取。
  • 安全传送：自动计算安全落点，失败拒绝传送；传送有 30 秒冷却。
  • 防重叠与间距：圈地自动校验重叠、出生点与联盟间距。

常见问题 ​

Q：伙伴进不来联盟领地？ 给伙伴所在职位开 move 旗标：/gclaim perm <领地> 成员 move ALLOW；或把档位调为「半开放/开放」。

Q：成员能建不能开箱？ 检查 container 旗标：/gclaim perm <领地> 成员 container ALLOW。

Q：联盟领地能被其他联盟破坏吗？ 不能。联盟领地默认只允许本盟成员按职位权限操作，其他联盟成员视为陌生人（受档位约束）。

Q：槽位用完了怎么办？ 通过繁荣度提升解锁，或用 /gclaim worldslot <世界> 购买世界扩展槽；单块联盟领地内最多 10 个子领地，可把设施分区建在子领地里。
