# 14. 基岩版与跨版本

## 14.1 基岩版连接

| 项目 | 内容 |
| --- | --- |
| 地址 | `pepper.ltd` |
| 端口 | `19132` |
| 认证 | 无需 Java 账号（Xbox Live 登录） |
| 名字前缀 | `BE-` |

基岩版玩家不需要 Java 账号，直接用 Xbox Live 账号进入。Java 玩家会看到基岩版玩家的名字带 `BE-` 前缀，例如 `BE-Steve`。

## 14.2 Java 版连接

- 地址 `pepper.ltd:25565`。
- 必须使用正版账号；离线/破解客户端无法登录。
- 建议使用较新的 1.21+ 客户端；部分旧版本仍可进入，但过旧的版本可能被拒绝。
- 不需要安装任何服务器专属模组；原版客户端即可。

## 14.3 跨版本限制

- 基岩版不能使用 Java 版模组、光影或部分资源包。
- 少数 Java 专属交互（如副手、部分命令提示）在基岩版上表现不同。
- 经济、领地、联盟、聊天数据互通，但客户端界面不同。
- 如果提示“过时的客户端”，请先更新游戏版本。
