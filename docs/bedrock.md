
# 基岩版玩家

基岩版玩家（手机/主机版）在服务器中同样可以方便地使用各项功能，还额外拥有**表单（GUI 菜单）**支持，操作更直观。

## 表单指令

| 指令 | 表单内容 |
|---|---|
| `/tpgui` | 传送表单（请求传送到其他玩家） |
| `/msggui` | 消息表单（给玩家发私聊） |
| `/homegui` | 家表单（管理你的家） |
| `/phomegui` | 公开家表单 |
| `/warpgui` | 传送点表单 |
| `/paygui` | 转账表单（给玩家转钻石） |

在表单界面点选即可完成操作，无需记忆复杂指令。

## 自动表单

- **死亡返回**：基岩版玩家死亡复活后，会自动弹出「返回死亡点」表单，可选择是否回到死亡地点。
- **传送请求**：收到其他玩家的传送请求时，会自动弹出接受/拒绝表单。

## 名字前缀

- 基岩版玩家进入服务器后，名字前会带有一个 **`.`** 前缀，用于与 Java 版玩家区分。
- 例如基岩玩家「小明」在服务器里显示为 `.小明`。

## 通用功能

基岩版玩家同样可以使用所有基础指令：

- 传送：`/spawn`、`/sethome`、`/home`、`/tpa`、`/warp`
- 聊天：`/msg`、`!all`
- 经济：`/money`、`/pay`、`/diamond`
- 联盟与领地：`/union`、`/pclaim`、`/gclaim`
- 前缀：`/prefix`
- QQ 绑定：`/qqbind`

## 小提示

- 使用表单是最省事的方式，基岩版玩家推荐优先使用 `/xxxgui` 系列。
- 如果想用传统指令，输入时注意基岩版自动补全会辅助你。
