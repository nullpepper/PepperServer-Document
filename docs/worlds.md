
# 世界

服务器有多个世界，各有不同的定位与规则。

## 世界一览

| 世界 | 定位 | 难度 | PvP | 说明 |
|---|---|---|---|---|
| **主城** | 大厅 / 安全区 | 和平 | 关闭 | 出生点、玩家聚集地，禁止打架 |
| **主世界** | 生存世界 | 困难 | 开启 | 主要的生存与建设世界 |
| **下界** | 资源与交通 | 简单 | 开启 | 获取下界资源，方便长距离移动 |
| **末地** | 挑战 | 简单 | 开启 | 挑战末影龙、获取末地资源 |

## 如何前往

| 方式 | 说明 |
|---|---|
| `/spawn` | 随时回到主城 |
| `/pej` | 在主城使用，弹射前往主世界 |
| 下界传送门 | 在主世界建造下界传送门，进入下界 |
| 末地传送门 | 在主世界寻找/搭建末地传送门，前往末地 |
| `/warp [名字]` | 若有设置好的传送点，可通过传送点快速移动 |

## 世界规则

- **主城**：和平模式、禁止 PvP，是安全区，请在这里社交、交易、挂机。
- **主世界**：困难模式、PvP 开启，是真正的生存挑战，注意护甲与食物。
- **下界 / 末地**：简单模式、PvP 开启，资源丰富但同样有风险。
- 在任何世界死亡都会**回到主城**重生（重生点统一在主城）。
- 主城范围内**无法圈地**。

## 小提示

- 出发冒险前记得 `/sethome` 设置家，随时安全返回。
- 下界与主世界的坐标比例为 1:8，在下界移动 100 格等于主世界 800 格。
