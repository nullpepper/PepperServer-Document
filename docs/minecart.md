# 9. 矿车工作站

## 9.1 基本操作

| 操作 | 效果 |
| --- | --- |
| 潜行 + 右键空矿车（手持方块） | 把方块装到矿车上，变成工作站矿车 |
| 右键工作站矿车 | 打开对应界面（工作台/容器等） |
| 潜行 + 右键工作站矿车 | 拆下方块，矿车恢复为空矿车 |

矿车可以像普通矿车一样被推动、上下坡和运输。

## 9.2 支持的工作站

本服 `allow-all-blocks: true`：除基岩、屏障外，**几乎所有方块都能放上矿车**。下表是有实际交互功能的类型；其他方块会变成装饰矿车（右键没有界面，仍可拆下）。

| 方块 | 效果 |
| --- | --- |
| 工作台 | 打开 3×3 合成 |
| 砂轮 | 打开砂轮界面 |
| 织布机 | 打开织布机界面 |
| 制图台 | 打开制图台界面 |
| 锻造台 | 打开锻造界面 |
| 切石机 | 打开切石机界面 |
| 附魔台 | 打开附魔界面 |

## 9.3 容器矿车

支持：木桶、投掷器、陷阱箱、潜影盒、合成器。

- 右键打开容器，可正常存取。
- 拆下时容器内的物品会全部掉到地上，容器以**空白物品**放进背包（`container-pickup-policy: DROP`）；请先清空再拆。
- 陷阱箱仍然是陷阱箱，打开会触发红石信号。

## 9.4 特殊矿车

| 方块 | 行为 |
| --- | --- |
| 发射器 | 9 格容器；矿车驶过**充能的激活铁轨**时随机弹出 1 个物品，约 2 秒一次 |
| 铁砧 | 可当移动铁砧使用；按原版铁砧规则受损（每次使用约 12% 概率降级/损毁） |
| 普通熔炉 | 变成原版熔炉矿车，可推动、可烧炼 |
| 烟熏炉 / 高炉 / 酿造台 | 仅外观，不提供对应功能 |
| 箱子/漏斗/熔炉/TNT/命令方块 | 放上空矿车后直接变成对应原版矿车；可正常使用，但**不能拆回方块**（防止刷物品） |

## 9.5 限制

- 不能骑乘工作站矿车。
- 拆下工作站矿车需要潜行右键；普通右键是打开界面。
- 容器矿车拆下时物品会散落，建议在安全处操作。
- 原版特殊矿车（箱子、漏斗、TNT 等）放下后无法收回，放置前想清楚。
- 在他人领地内放置、拆下或打开矿车方块会被领地保护拦截；发射器矿车在禁止生物破坏方块的领地里也不会弹出物品。
