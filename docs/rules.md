# 2. 基础设定与游戏规则

## 2.1 核心参数

| 参数 | 当前值 |
| --- | --- |
| 难度 | 主世界困难；下界/末地简单；主城和平 |
| 死亡掉落 | **默认开启**（服务器文件未启用 keepInventory；以游戏内 `/gamerule keepInventory` 为准） |
| 野外 PvP | 开启 |
| 领地内 PvP | 默认关闭，可由领地旗标开启 |
| 爆炸破坏方块 | **领地内默认关闭**（`tnt`/`explode` 旗标）；野外 TNT 等仍会破坏，生物爆炸受 `mobGriefing` 影响 |
| 火焰蔓延 | **领地内默认关闭**（`firespread` 旗标）；野外按原版规则 |
| 世界边界 | 未在配置中固定（以 `/worldborder get` 为准） |
| 后端人数上限 | 1,000（代理列表显示的 2,333 是展示值） |
| 白名单 | 关闭 |
| 视距 / 模拟距离 | 10 / 10 |

> 死亡会掉落物品与经验；药水效果、位置和时间也会损失。贵重物品请存箱、放领地或末影箱。困难难度下怪物伤害较高，下界与末地尤其危险。
>
> 领地内爆炸不破坏方块、火焰不蔓延；野外 TNT 仍会炸方块、火仍会蔓延，请勿在主城或他人建筑附近测试。爆炸与火焰仍会造成实体伤害。

## 2.2 社区约定（非官方规则）

以下内容是社区通行做法，**不是管理组正式规则**；最终以游戏内公告和管理组处理为准。

- 不偷窃、不破坏他人领地，不绕过领地保护。
- 不利用漏洞、复制物品或刷取经济；发现漏洞请报告管理组。
- 不刷屏、不发布广告、不进行人身攻击。
- 野外可以 PvP，但不要在他人明确表示不愿对战后持续骚扰。
- 大型红石、大量实体或高频操作请控制规模，避免影响其他玩家。
- 进入他人领地前先打招呼；未经允许不要拿取容器物品。

## 2.3 基础常用命令

| 命令 | 作用 |
| --- | --- |
| `/spawn` | 回主城出生点 |
| `/back` | 回上一个传送点或死亡点 |
| `/warp court` | 去主城观景台 |
| `/warps` | 查看可用传送点 |
| `/tpa <玩家>` | 请求传送到对方 |
| `/tpahere <玩家>` | 请求对方传送到你 |
| `/tpaccept` / `/tpyes` | 接受传送请求 |
| `/tpdeny` / `/tpno` | 拒绝传送请求 |
| `/tpignore` | 忽略他人的传送请求 |
| `/help` | 查看服务器命令帮助 |
