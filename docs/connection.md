# 1. 连接与快速开始

## 1.1 服务器地址

| 项目 | 内容 |
| --- | --- |
| Java 版地址 | `pepper.ltd:25565` |
| 基岩版地址 | `pepper.ltd:19132` |
| Java 版认证 | 仅正版账号 |
| 基岩版认证 | 无需 Java 账号，用 Xbox Live 账号直接进入 |
| 服务器版本 | 26.3 |
| 客户端版本 | 建议使用较新的 1.21+ 客户端；过旧的版本可能无法进入 |

Java 版和基岩版进入的是同一个服务器，聊天、经济、领地、联盟数据互通。

## 1.2 第一次进入建议流程

1. 进入后先输入 `/spawn`，确认自己在主城。
2. 在主城输入 `/ej`，5 秒后会被弹射到主世界随机落点。主城全境不能圈地，所以**先离开主城**；另外每个世界的出生点 100 格内也不能完整圈地。
3. 落地后手持普通金锄，**左键**点第一个角、**右键**点对角，再输入 `/pclaim create <名字>`，圈一块个人领地（免费，消耗领地额度）。
4. 用 `/sethome home` 设一个个人传送点；再用 `/pclaim settp` 给领地设一个领地传送点。
5. 挖到的钻石可以放进银行：`/bank add <数量>`，避免随身携带。
6. 迷路或卡住：`/spawn` 回主城，`/back` 回上一个位置或死亡点。

## 1.3 主城与世界

| 世界 | 说明 |
| --- | --- |
| 主城 | 独立的主城区域，下方是虚空；和平难度，禁止 PvP |
| 主世界 | 主要生存世界，难度困难；世界边界 100,000 格宽 |
| 下界 | 可通过传送门进入 |
| 末地 | 可通过末地传送门进入 |

主城**全境不能创建领地**；此外每个世界的出生点 **100 格内不能完整圈地**。主城可用 `/warp court` 前往观景台，用 `/spawn` 回出生点。
