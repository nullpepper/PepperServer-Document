# 16. 常见问题

**Q：为什么我有 8 钻石余额，背包里却没有钻石？**
A：8 是初始记账余额。用 `/bank takeout 8` 取出钻石，或直接用它买东西/转账。

**Q：为什么我挖了钻石，余额没变？**
A：挖到的钻石是物品，不是余额。需要 `/bank add <数量>` 存入。

**Q：为什么我不能在自家领地破坏方块？**
A：确认你是领地屋主，且没有把自己分配到一个没有 `build` 权限的组。用 `/pclaim info` 和 `/pclaim explain <领地> build` 检查。

**Q：为什么别人能走进我的领地？**
A：默认 `move=true`，领地不是封闭盒子；外人只是不能破坏/开箱子/用按钮。想完全禁止进入，把 `move` 设为 `off`。

**Q：为什么我不能开自家箱子？**
A：先用 `/pclaim explain <领地> container` 看是哪条规则拒绝；屋主一般不受成员组限制，若仍被拒绝，检查是否与主城保护区等其他保护重叠。

**Q：为什么领地内不能 PvP？**
A：领地默认 `pvp=off`。屋主可开启；有外人在场时不能改，需要先让对方离开。

**Q：为什么我只能有一块个人领地？**
A：当前每人限 1 块。联盟领地是另一套系统，需要加入联盟后使用 `/gclaim`。

**Q：为什么第 9 个家要收费？**
A：前 8 个传送点免费，第 9 个起每个 8 钻石；公开传送点每个 16 钻石。

**Q：为什么 `/home` 和 `/pclaim home` 不一样？**
A：`/home` 是个人传送点；`/pclaim home` 是回自己的领地（优先用 `/pclaim settp` 设的领地传送点，没设则落领地中心）。两者独立。

**Q：为什么我的联盟一直是 Lv.1？**
A：联盟等级固定为 Lv.1，不会增长；人数上限 10、免费领地额度 1,024。扩容只能买额度。

**Q：联盟领地扩容为什么这么贵？**
A：按当前价格 100 钻石/格，从联盟金库扣；1 格 100 钻石，256 格 25,600 钻石。建议先用免费 1,024 格，确有必要再买。

**Q：为什么我不能创建联盟领地？**
A：需要盟主或拥有 `union.claim.create` 权限的职位；普通成员只能建造和使用。用 `/union rank` 检查职位权限。

**Q：死亡会掉东西吗？**
A：不会。死亡后背包物品保留；但药水效果、位置和时间仍会损失。

**Q：主世界有多大？**
A：有。主世界 100,000 格宽、下界 12,500 格宽、末地 50,000 格宽。

**Q：基岩版名字为什么带 `BE-`？**
A：这是系统给基岩版玩家加的前缀，用于区分 Java 版和基岩版玩家；不影响游戏功能。

**Q：Java 版可以用离线账号吗？**
A：不能。服务器要求正版验证，必须使用正版账号。

**Q：想找的功能这里没有怎么办？**
A：先看 [本服没有的功能](unavailable.md)，那里列了本服不提供的内容。

**Q：发现 bug 或被骗怎么办？**
A：保留截图/录屏、时间、地点和玩家名，联系在线管理员。不要自行利用漏洞。
