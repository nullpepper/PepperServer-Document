# 12. 休闲动作与外观

## 12.1 动作

| 命令 | 动作 |
| --- | --- |
| `/sit` | 坐下/起身（可切换） |
| `/lay` | 躺下 |
| `/legsup` | 抬腿坐 |
| `/spin` | 旋转 |
| `/crawl` | 爬行 |

- 空手右键台阶、半砖、楼梯可以坐下；潜行起身。
- 动作是服务器同步的玩家姿势，移动、受伤或传送会中断。
- 不要在领地边界或危险位置摆姿势，以免被打断后掉进危险区域。

## 12.2 图片显示

在聊天中发送以 `.png`、`.jpg`、`.gif`、`.webp` 等结尾的图片直链，服务器会把图片渲染成地图预览。链接必须可公开访问；图片过大（默认上限 5 MB）或格式不支持时会失败。请勿发送违规图片，图片内容仍受聊天规则约束。
