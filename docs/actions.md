
# 休闲动作

在服务器里可以做出各种休闲动作，丰富你的游戏体验。

## 动作指令

| 指令 | 作用 |
|---|---|
| `/sit` | 坐下 |
| `/lay` | 躺下 |
| `/layback` | 仰躺 |
| `/crawl` | 匍匐前进 |
| `/spin` | 旋转 |
| `/bellyflop` | 趴着扑倒 |

## 使用说明

- **坐下**：对台阶、楼梯、地毯等方块点击即可坐下；也可以手动输入 `/sit`。
- 用 `/sit toggle` 可以切换「点击方块自动坐下」开关。
- 再次执行对应指令或按 Shift 起身。

## 可坐的方块

- 楼梯、台阶、地毯、羊毛地毯、苔藓地毯、苍白苔藓地毯、雪等。

## 注意事项

- 动作只是休闲玩法，不影响生存属性。
- 请不要恶意在别人身上堆叠动作刷屏。
