# 管理指令

> ⚠️ 以下指令**仅管理员/管理组成员**可以使用，普通玩家请勿尝试。
> 普通玩家输入这些指令会提示无权限。

## 传送与位置管理

| 指令 | 作用 |
|---|---|
| `/setspawn` | 设置主城出生点 |
| `/setwarp <名字>` | 设置传送点 |
| `/delwarp <名字>` | 删除传送点 |
| `/mv tp <世界>` | 传送到指定世界 |
| `/mv list` | 查看所有世界 |
| `/mv info <世界>` | 查看世界信息 |

## 建筑与保护

| 指令 | 作用 |
|---|---|
| `/rg claim <区域名>` | 圈定保护区域 |
| `/rg remove <区域名>` | 删除区域 |
| `/rg addmember <区域名> <玩家>` | 添加区域成员 |
| `/rg flag <区域名> <标志> <值>` | 设置区域标志 |
| `/co i` | 切换查询模式（查看方块被谁改动） |
| `/co near` | 查看附近的改动记录 |
| `/co lookup` | 高级查询 |

## 玩家管理

| 指令 | 作用 |
|---|---|
| `/vanish` | 隐身（对普通玩家不可见） |
| `/vanish-show` | 取消隐身 |
| `/invsee <玩家>` | 查看/编辑玩家背包 |
| `/invsee clear <玩家>` | 清空玩家背包 |
| `/eco give <玩家> <金额>` | 发放钻石 |
| `/eco take <玩家> <金额>` | 扣除钻石 |
| `/diamond add <玩家> <数量>` | 往玩家账户加钻石 |
| `/diamond take <玩家> <数量>` | 从玩家账户扣钻石 |
| `/diamond get <玩家>` | 查看玩家账户 |

## 联盟与领地管理

| 指令 | 作用 |
|---|---|
| `/union reload` | 热重载联盟配置 |
| `/union compensations <list\|retry\|finish>` | 联盟资金补偿人工核查 |
| `/pclaim admin` | 领地管理（详情见 PepperClaim 服主文档） |

## 性能与维护

| 指令 | 作用 |
|---|---|
| `/tps` | 查看服务器卡顿情况 |
| `/profiler` | 性能分析 |
| `/trchat reload` | 重载聊天配置 |
| `/prefixadmin reload` | 重载前缀配置 |
| `/custommsg reload` | 重载机器人自定义消息 |

## 物品与插件

| 指令 | 作用 |
|---|---|
| `/plugman` | 插件管理（加载/卸载/重载） |
| `/aup` | 自动更新插件管理 |

> 请务必谨慎使用管理指令，误操作可能影响玩家数据。
