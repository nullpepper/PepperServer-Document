# 3. 聊天与社交

## 3.1 聊天频道

服务器默认频道是 **Global（全球）**，直接打字即可在全服发言。

| 频道 | 进入方式 | 用途 |
| --- | --- | --- |
| Global | 默认；`/channel Global` | 全服聊天 |
| Union | `/channel Union`；或 `/union chat <消息>` | 联盟内部聊天 |
| 私聊 | `/msg <玩家> <消息>` | 一对一私聊 |

`/channel` 可以查看、加入、离开和切换频道。聊天栏会显示你的称号、联盟标签和名字。

## 3.2 私聊与屏蔽

| 命令 | 作用 |
| --- | --- |
| `/msg / /w / /tell / /m / /whisper <玩家> <消息>` | 私聊 |
| `/reply / /r <消息>` | 回复最近给你发私聊的人 |
| `/ignore <玩家>` | 屏蔽某人的聊天与私聊 |
| `/ignore` | 查看/管理屏蔽列表 |

## 3.3 聊天限制

- 发言冷却 **2 秒**。
- 单条消息最多 **100 个字符**。
- 有相似度防刷屏检测，连续重复内容可能被拦截。
- 彩色文字需要对应权限；普通玩家请使用纯文本，带 `&` 的彩色内容可能被过滤。
- 联盟频道只对同联盟成员可见。

## 3.4 图片显示

在聊天中发送以 `.png`、`.jpg`、`.jpeg`、`.bmp`、`.gif`、`.webp` 结尾的图片直链，服务器会把图片渲染成**地图预览**贴进聊天栏。

- 链接必须**可公开访问**：需要登录、带防盗链的图床会加载失败。
- 单张图片上限 **5 MB**；GIF 按动图逐帧播放。
- 预览显示约 9 秒后自动消失；`/preview cancel` 可提前关闭，`/preview history [条数]` 能列出最近发过的图片链接（默认 10 条）。
- 图片内容同样受聊天规则约束，请勿发送违规图片。
