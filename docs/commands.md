# 14. 命令速查表

## 14.1 基础与传送

| 命令 | 作用 |
| --- | --- |
| `/spawn` | 回主城 |
| `/back` | 回上一个位置/死亡点 |
| `/warp court` | 主城观景台 |
| `/warps` | 公共传送点列表 |
| `/tpa <玩家>` | 请求传送到对方 |
| `/tpahere <玩家>` | 请求对方传送到你 |
| `/tpaccept` / `/tpdeny` | 接受/拒绝 |
| `/tpignore` | 忽略传送请求 |
| `/rtp` | **不可用** |

## 14.2 传送点

| 命令 | 作用 |
| --- | --- |
| `/sethome <名字>` | 设置传送点 |
| `/home <名字>` | 前往传送点 |
| `/home` | 传送点列表 |
| `/delhome <名字>` | 删除传送点 |
| `/homelist` | 列出传送点 |
| `/homes` | 传送点界面 |
| `/phome <玩家>.<传送点>` | 访问公开传送点 |

## 14.3 经济

| 命令 | 作用 |
| --- | --- |
| `/balance` | 查看余额 |
| `/pay <玩家> <金额>` | 转账 |
| `/baltop` | 余额排行 |
| `/paytoggle` | 开关接收转账 |
| `/bank` | 银行界面 |
| `/bank add <数量>` | 存钻石 |
| `/bank takeout <数量>` | 取钻石 |
