# 11. 称号系统

## 11.1 当前称号

| ID | 显示名 | 获取方式 |
| --- | --- | --- |
| `default` | 玩家 | 默认拥有 |
| `contributor` | 贡献者 | 管理组发放，目前仅少数玩家拥有 |

> 佩戴的称号会显示在聊天消息的玩家名前。

## 11.2 命令

```text
/title                打开称号界面
/prefix               打开称号界面
/title list           列出可用称号
/title select <称号>  佩戴称号
/title info           查看当前称号
```

称号会显示在聊天栏名字前，也会影响部分界面显示。

贡献者称号由管理组根据贡献发放；普通玩家无法自行获取。
