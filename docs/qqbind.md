
# QQ 绑定

将你的游戏账号与 QQ 绑定，可以享受更多便利（如白名单保护、联系客服等）。

## 绑定流程

**第一步：在游戏里发起绑定**

```
/qqbind bind <你的QQ号>
```

系统会提示绑定请求已发送。

**第二步：在 QQ 群内发送验证码**

游戏内会提示你在指定的 QQ 群中发送一个**验证码**（纯数字）。请在群内发送该验证码完成确认。

**第三步：完成绑定**

绑定成功后，你的游戏账号与 QQ 就关联在一起了。

## 常用指令

| 指令 | 作用 |
|---|---|
| `/qqbind bind <QQ号>` | 发起绑定请求 |
| `/qqbind confirm <QQ号>` | 确认来自某 QQ 的绑定请求 |
| `/qqbind` | 查看绑定帮助 |

## 注意事项

- 一个 QQ 只能绑定一个游戏账号，反之亦然。
- 验证码有**有效期**，超时后需要重新发起。
- 请勿把验证码发给陌生人，只发送给官方群。
- 如果绑定失败或有疑问，请在 QQ 群内联系管理员。
