
# 繁荣度与活跃度

联盟的**活跃度**（繁荣度）反映联盟成员的活跃程度，由成员在联盟领地内的活动积累而来，**无法用钻石购买**。

## 活跃度来源

成员在联盟领地内的活动会为联盟积累活跃度：

| 活动 | 说明 |
|---|---|
| 生产 | 在联盟领地内采集/耕种等生产行为 |
| 狩猎 | 在联盟领地内击杀生物 |
| 驻留 | 在联盟领地内停留 |
| 访客 | 联盟领地接待的访客 |

## 繁荣度档位

联盟活跃度达到阈值后解锁更高档位，领地之心效果与展示随之升级：

| 档位 | 图标 | 活跃度阈值 |
|---|---|---|
| **铜锭** | 铜锭 | 200 |
| **铁锭** | 铁锭 | 450 |
| **金锭** | 金锭 | 800 |
| **下界之星** | 下界之星 | 1200 |
| 沉眠 | 灰色染料 | 长期无活跃 |

## 查看繁荣度

| 指令 | 作用 |
|---|---|
| `/gclaim prosperity` | 查看联盟繁荣度详情 |
| `/gclaim top` | 查看全服活跃榜 |

## 领地之心

把满级信标注册为联盟的**领地之心**（灯塔），可解锁传送与特效：

| 指令 | 作用 |
|---|---|
| `/gclaim heart register` | 把脚下满级信标注册为领地之心 |
| `/gclaim heart unregister` | 注销领地之心 |
| `/gclaim heart effect` | 查看/切换特效 |
| `/gclaim heart info` | 查看领地之心信息 |
| `/gclaim heart public on/off` | 开关公开传送（银锭档位以上） |

## 与联盟等级的关系

联盟活跃度会联动上报给[联盟](index.md#等级与经验)系统转化为联盟经验，帮助联盟升级、提升成员上限——越活跃的联盟越强大。
