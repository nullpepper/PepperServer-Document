# 5. 经济系统

## 5.1 货币就是钻石

服务器使用 **钻石** 作为唯一货币，通过 XConomy 记账。

| 项目 | 规则 |
| --- | --- |
| 新玩家初始余额 | **8 钻石** |
| 转账税 | 0 |
| 银行兑换比例 | **1 钻石 = 1 余额**，双向 1:1 |
| 余额显示 | `/balance` 显示“多少钻石” |
| 排行榜 | `/baltop` |

> 余额是“记账数字”，不是背包里的钻石。`/balance` 有 8，不代表背包有 8 颗钻石；需要用 `/bank takeout` 取出来。

## 5.2 银行（PepperDiamond）

| 命令 | 作用 |
| --- | --- |
| `/bank` | 打开银行界面 |
| `/bank add <数量>` | 把背包里的钻石存入余额；别名 `/bank save` |
| `/bank takeout <数量>` | 从余额取出钻石到背包；别名 `/bank get`、`/bank take` |

银行只处理钻石，其他物品不能存入。存取是 1:1，没有手续费。

## 5.3 玩家转账

| 命令 | 作用 |
| --- | --- |
| `/pay <玩家> <金额>` | 转账给对方 |
| `/paytoggle` | 开启/关闭接收转账 |
| `/balance` | 查看余额 |
| `/baltop` | 查看余额排行榜 |

转账不收税。交易前确认对方身份，服务器不会自动撤回玩家之间的自愿转账。

## 5.4 赚钱与花钱

当前**没有系统商店、拍卖行或任务奖励**。获取钻石的主要方式是挖矿、探索和与其他玩家交易。

主要支出：

- 第 9 个及以后的家园：每个 8 钻石。
- 公开家园：每个 16 钻石。
- 家园领地扩容：注释价 0.05 钻石/格；**当前配置实际 5 钻石/格**（用余额购买额度，见下方价格提示）。
- 联盟创建：64 钻石。
- 联盟领地扩容：注释价 1 钻石/格；**当前配置实际 100 钻石/格**（从联盟金库扣）。

**价格提示（重要）**：`PepperClaim/economy.yml` 的注释写的是「0.05 货币/块」与「1 货币/块」，但配置值分别是 `5.0` 与 `100.0`；插件把 `economy.yml` 的数值直接当作「钻石/格」（内部 ×100 存为「分」），并不存在把 0.05 再乘 100 的二次放大；100 倍差异来自配置值本身写成了 `5.0` 而不是 `0.05`。按当前配置，2,048 格约需 10,240 钻石，而不是 102.4 钻石。购买确认界面会显示实际扣费；GUI 的额度购买一次是 256 格（家园约 1,280 钻石、联盟约 25,600 钻石），想试价请用命令买 1 格。在管理组修正配置前，不建议直接用 GUI 大批购买。
