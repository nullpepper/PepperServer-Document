# 10. 主城弹射 PepperEject

## 10.1 用法

在主城（Spawn 世界）输入：

```text
/ej
```

别名 `/pej`。

## 10.2 效果

1. 5 秒倒计时。
2. 把你弹射到世界高度上限附近（约 **y=320**；配置里的 500 会被钳制到世界最大高度）。
3. 落点在主世界以 `(0,0)` 为圆心、**半径 1000 格**的圆内随机选择。
4. 落地时播放爆炸特效，并获得 **20 秒摔落伤害免疫**。

## 10.3 注意

- 只能在主城使用；在主世界、下界、末地输入会被拒绝。
- 落点是随机安全点，但服务器只保证“尽量安全”，不保证落点周围没有怪、岩浆或悬崖。
- 落地后 20 秒内免摔落伤害，但其他伤害（怪物、岩浆、窒息）照常。
- 建议落地前看清坐标（Java 版按 F3，基岩版打开坐标显示），落地后立刻 `/sethome` 或记坐标。
