# 10. 主城弹射

## 10.1 用法

在主城输入：

```text
/ej
```

别名 `/pej`。

## 10.2 效果

1. 5 秒倒计时。
2. 把你弹射到高空（约 **y=319**，接近世界高度上限）。
3. 落点在主世界以 `(0,0)` 为圆心、**半径 1000 格**的圆内随机选择。
4. 从弹射那一刻起给你 **20 秒摔落保护**；正常落地会消耗掉这次保护，并在落地处播放一圈粒子与爆炸音效，同时显示 `Boom~`。

## 10.3 注意

- 只能在主城使用；在主世界、下界、末地输入会被拒绝。
- 落点是随机安全点，但服务器只保证“尽量安全”，不保证落点周围没有怪、岩浆或悬崖。
- **摔落保护不是“落地后再给 20 秒”**：它从弹射瞬间开始计时，共 20 秒，用来兜住这一跳；落地时就被用掉，所以**落地之后再跳崖照常摔伤**。若这一跳没造成摔落伤害（例如落进水里），保护不会被消耗，会保留到 20 秒结束。其他伤害（怪物、岩浆、窒息）全程照常。
- 建议落地前看清坐标（Java 版按 F3，基岩版打开坐标显示），落地后立刻 `/sethome` 或记坐标。
