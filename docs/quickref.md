# 常用指令速查

> 说明：`<>` 表示必填参数，`[]` 表示可选参数。完整说明见各功能页面。

## 传送

| 指令 | 作用 |
|---|---|
| `/spawn` | 回到主城 |
| `/sethome [名字]` | 设置家 |
| `/home [名字]` | 回家 |
| `/delhome [名字]` | 删除家 |
| `/homes` | 查看家列表 |
| `/warp [名字]` | 前往传送点 |
| `/back` | 返回上次位置（死亡/传送前） |
| `/tpa <玩家>` | 请求传送到该玩家身边 |
| `/tpahere <玩家>` | 邀请该玩家传送到你身边 |
| `/tpaccept` | 接受传送请求 |
| `/tpdeny` | 拒绝传送请求 |
| `/pej` | 在主城使用，弹射前往主世界 |

## 聊天

| 指令 | 作用 |
|---|---|
| `/msg <玩家> <内容>` | 私聊（别名 `/tell` `/m` `/w`） |
| `!all <内容>` | 全服喊话（也可用 `/global` `/shout`） |
| `/trchat color <颜色>` | 设置聊天颜色 |
| `/ignore <玩家>` | 忽略某玩家的聊天 |

## 经济

| 指令 | 作用 |
|---|---|
| `/money` | 查看余额（别名 `/balance` `/bal`） |
| `/baltop` | 查看富豪榜 |
| `/pay <玩家> <金额>` | 转账 |
| `/diamond` | 打开钻石银行界面（别名 `/bank`） |

## 联盟与领地

| 指令 | 作用 |
|---|---|
| `/union help` | 打开联盟帮助 |
| `/union create <名字>` | 创建联盟 |
| `/union list` | 查看联盟列表 |
| `/pclaim auto` | 一键自动安家（自动圈一块 16×16 的领地） |
| `/pclaim home` | 传送回家园领地 |
| `/pclaim gui` | 打开领地图形界面 |
| `/pclaim map` | 查看周边领地地图 |
| `/gclaim create <名字>` | 创建联盟领地 |

## 生活

| 指令 | 作用 |
|---|---|
| `/prefix` | 打开前缀（称号）界面 |
| `/sit` | 坐下 |
| `/lay` | 躺下 |
| `/crawl` | 匍匐前进 |
| `/imagepreviewer preview <图片链接>` | 在聊天中预览图片 |

## 基岩版玩家

| 指令 | 作用 |
|---|---|
| `/tpgui` | 传送表单 |
| `/msggui` | 消息表单 |
| `/homegui` | 家表单 |
| `/phomegui` | 公开家表单 |
| `/warpgui` | 传送点表单 |
| `/paygui` | 转账表单 |

## QQ 绑定

| 指令 | 作用 |
|---|---|
| `/qqbind bind <QQ号>` | 发起绑定 |
| `/qqbind confirm <QQ号>` | 确认绑定 |
