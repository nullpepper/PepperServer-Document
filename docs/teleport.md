# 4. 传送与家园

## 4.1 个人家园（HuskHomes）

| 项目 | 规则 |
| --- | --- |
| 家园数量上限 | 16 个 |
| 免费家园 | 前 8 个 |
| 第 9 个起 | 每个 **8 钻石**（从余额扣） |
| 公开家园 | 每个 **16 钻石**，最多 5 个 |
| 传送预热 | 2 秒；移动或受伤会取消 |
| 家名 | 最多 16 字符，默认允许中文 |

常用命令：

```text
/sethome <名字>          设置家
/home <名字>             回家
/home                    打开家园列表
/delhome <名字>          删除家
/homelist                列出自己的家
/homes                   打开家园 GUI
/phome <玩家>.<家名>     访问别人的公开家
```

> `/home` 是 HuskHomes 的个人家园；`/pclaim home` 是传送到你的领地，两者不是同一个系统。

## 4.2 主城、传送点与回退

| 命令 | 说明 |
| --- | --- |
| `/spawn` | 回主城 |
| `/warp court` | 主城观景台（当前主要公共传送点） |
| `/warps` | 列出全部公共传送点 |
| `/back` | 回上一个传送点或死亡点 |

目前公共传送点很少，`/warp court` 是主城高台；不要把它当成随机传送。

## 4.3 玩家传送

| 命令 | 说明 |
| --- | --- |
| `/tpa <玩家>` | 请求传送到对方 |
| `/tpahere <玩家>` | 请求对方传送到你 |
| `/tpaccept` / `/tpyes` | 接受 |
| `/tpdeny` / `/tpno` | 拒绝 |
| `/tpignore` | 不再接收某人的请求 |

传送请求有时效，过期后需要重新发送。

## 4.4 随机传送不可用

`/rtp` 在当前服务器被**禁用**（命令关闭且权限拒绝）。想离开主城请用 `/ej` 弹射，想去远处请自行赶路或使用传送请求。
