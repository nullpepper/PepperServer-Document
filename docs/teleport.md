# 4. 传送与个人传送点

## 4.1 个人传送点

| 项目 | 规则 |
| --- | --- |
| 传送点数量上限 | 16 个 |
| 免费传送点 | 前 8 个 |
| 第 9 个起 | 每个 **8 钻石**（从余额扣） |
| 公开传送点 | 每个 **16 钻石**，最多 5 个 |
| 传送预热 | 2 秒；移动或受伤会取消 |
| 传送点名 | 最多 16 字符，默认允许中文 |

常用命令：

```text
/sethome <名字>          设置传送点
/home <名字>             前往传送点
/home                    打开传送点列表
/delhome <名字>          删除传送点
/homelist                列出自己的传送点
/homes                   打开传送点 GUI
/phome <玩家>.<传送点>   访问别人的公开传送点
```

> `/home` 是个人传送点；`/pclaim home` 是回自己的领地（优先用 `/pclaim settp` 设的领地传送点，没设则落领地中心），两者不是同一个系统。

## 4.2 主城、公共传送点与回退

| 命令 | 说明 |
| --- | --- |
| `/spawn` | 回主城 |
| `/warp court` | 主城观景台 |
| `/warps` | 列出全部公共传送点 |
| `/back` | 回上一个传送点或死亡点 |

`/warp court` 是固定的主城观景台；想随机去主世界开荒请用 `/ej`。

## 4.3 玩家传送

| 命令 | 说明 |
| --- | --- |
| `/tpa <玩家>` | 请求传送到对方 |
| `/tpahere <玩家>` | 请求对方传送到你 |
| `/tpaccept / /tpyes` | 接受 |
| `/tpdeny / /tpno` | 拒绝 |
| `/tpignore` | 不再接收某人的请求 |

传送请求有时效，过期后需要重新发送。

## 4.4 随机传送

主城提供 `/ej` 弹射，它就是本服的随机传送：只在主城可用，输入后 5 秒倒计时，把你弹到主世界以 (0,0) 为圆心、半径 1000 格的随机安全落点，并给一次摔落保护（从弹射起算 20 秒，落地即用掉）。它不能指定目的地，也不能在主世界再次使用；想精确去某处请用 `/tpa` 或自行赶路。
