# 7. 联盟 PepperUnion

## 7.1 基本规则

| 项目 | 规则 |
| --- | --- |
| 创建费用 | **64 钻石**（从创建者余额扣，不进入联盟金库） |
| 联盟名长度 | 2–24 字符 |
| 允许字符 | 中文、字母、数字、下划线 |
| 创建确认 | 5 秒内 `/union confirm` |
| 邀请有效期 | 10 分钟 |
| 申请有效期 | 7 天 |
| 当前联盟等级 | **固定 Lv.1** |
| Lv.1 人数上限 | **10 人** |
| Lv.1 免费领地额度 | **1,024 格** |

> 重要：配置里虽然写了 2–10 级的升级曲线，但当前版本**没有任何玩法会给予联盟经验**，所以所有联盟都停留在 Lv.1。不要按旧文档的“等级表”规划人数或领地；想扩容只能花钻石购买。

## 7.2 创建与加入

```text
/union create <名称>            创建联盟（64 钻石，5 秒内确认）
/union confirm                  确认创建/解散等操作
/union invite <玩家>            邀请玩家
/union accept <联盟编号>        接受邀请（编号见邀请提示/联盟列表）
/union join <联盟编号> [留言]   主动申请加入（/union apply 为兼容别名）
/union audit                    打开入盟申请审核界面
/union info [联盟编号]          查看联盟信息
/union list                     查看联盟列表与编号
```

- 邀请 10 分钟内有效。
- 主动申请 7 天内有效，盟主/有权限的职位在 `/union audit` 里处理。
- 退出或被踢后重新加入没有额外冷却（当前配置为 0）。

## 7.3 职位与权限

新建联盟默认有两个职位：

| 职位 | 默认权限 |
| --- | --- |
| 盟主 | 管理成员、创建/管理联盟领地、设置旗标、购买额度、管理金库 |
| 成员 | 进入联盟领地、建造、使用容器、骑乘、传送 |

盟主可以用 `/union rank` 打开职位管理界面，自建职位并分配权限。默认成员在联盟领地内可以建造和使用容器；如果不想让所有成员都能动，需调整职位权限。

同联盟成员之间默认不能互相攻击（`pvp.protect-allies: true`，服务端固定开启），盟主不能通过职位关闭；该保护只对联盟内成员生效。

## 7.4 联盟金库

```text
/union account                  打开金库界面
/union account balance          查看余额
/union account deposit <金额>   从个人余额存入
/union account withdraw <金额>  从金库取到个人余额（需取款权限）
/union account log              查看流水
```

- 金库是独立的联盟资金，不属于任何个人。
- 创建联盟的 64 钻石**不会**进入金库。
- 联盟领地扩容从金库扣款。
- 取款权限由职位控制；默认盟主可操作。

## 7.5 联盟聊天

```text
/union chat <消息>
```

也可以 `/channel Union` 切换到联盟频道，再直接发言。联盟频道只有同联盟成员可见。

## 7.6 联盟领地（`/gclaim`）

联盟领地与个人领地是两套系统，命令前缀不同。

| 项目 | 规则 |
| --- | --- |
| 初始额度 | 1,024 格（Lv.1） |
| 每级增加 | +512 格（当前等级不增长） |
| 额度上限 | 4,096 格 |
| 购买价格 | **当前实际 100 钻石/格**（注释 1，见 5.4 价格提示），从联盟金库扣 |
| 领地数量 | 不限（只受总面积限制） |
| 最小边长 | 3 格 |
| 最大边长 | 128 格 |
| 最大长宽比 | 8:1 |
| 子领地 | 每块主领地最多 10 块，仅一层 |
| 子领地边长 | 3–64 格 |
| 与其他联盟领地间距 | 至少 8 格 |
| 主城保护半径 | 100 格内不可圈地 |

常用命令：

```text
/gclaim                        打开联盟领地界面
/gclaim create <名称>          用金锄选区后创建
/gclaim info [领地]            查看信息
/gclaim list                   列出联盟领地
/gclaim quota                  查看额度
/gclaim buy <格数>             用联盟金库购买额度
/gclaim expand <格数> [方向]   扩边
/gclaim resize <领地>          重新选区后应用
/gclaim tp                     传送到联盟领地
/gclaim settp                  设置联盟领地传送点
/gclaim flag ...               设置旗标
/gclaim perms <领地>          查看领地权限
/gclaim perm <领地> <职位> <旗标> <值>
                              设置职位权限
/gclaim ban/unban ...          封禁/解封
/gclaim sub create <名称>      创建子领地
/gclaim map / borders          地图、边界显示
/gclaim delete <领地>          删除
```

说明：

- 联盟领地创建/管理需要盟主或对应职位权限；普通成员主要是在领地内建造、使用容器和传送。
- 联盟领地没有自动创建命令；必须先用金锄选区，再 `/gclaim create <名称>`。
- 单边 128 是硬上限，但面积上限 4,096 会先触发；实际形状通常不超过 64×64 的正方形，只有狭长形状才可能用到 128 边。
- 购买额度当前实际 100 钻石/格（注释写 1 钻石/格，见 5.4 价格提示），通常先用免费额度。
- 子领地只有一层，不能嵌套；每块主领地上限 10 块。
- 联盟领地与个人领地不能重叠。

## 7.7 成员管理

```text
/union kick <玩家>            踢出成员
/union ban <玩家> [原因]      封禁成员
/union unban <玩家>           解除封禁
/union transfer <玩家>        转让盟主
/union leave                  退出联盟
/union disband                解散联盟
/union rename <新名称>        改名
/union rank                   职位管理
```

`/union leave`、`/union disband` 等操作需要二次确认；按提示在 5 秒内输入 `/union confirm`。
