# 7. 联盟

## 7.1 基本规则

| 项目 | 规则 |
| --- | --- |
| 创建费用 | **64 钻石**（从创建者余额扣，不进入联盟金库） |
| 联盟名长度 | 2–24 字符 |
| 允许字符 | 中文、字母、数字、下划线 |
| 创建确认 | 5 秒内 `/union confirm` |
| 邀请有效期 | 10 分钟 |
| 申请有效期 | 7 天 |
| 当前联盟等级 | **固定 Lv.1** |
| 人数上限 | **10 人** |
| 免费领地额度 | **1,024 格** |

> 联盟等级固定为 Lv.1；想扩大人数或领地只能花钻石购买额度。

## 7.2 创建与加入

```text
/union create <名字>            创建联盟（64 钻石，5 秒内确认）
/union confirm                  确认创建/解散等操作
/union invite <玩家>            邀请玩家
/union accept <联盟编号>        接受邀请（编号见邀请提示/联盟列表）
/union join <联盟编号> [留言]         主动申请加入
/union apply <联盟编号> [留言]        主动申请加入
/union audit                    打开入盟申请审核界面
/union info [联盟编号]          查看联盟信息
/union list                     查看联盟列表与编号
```

- 邀请 10 分钟内有效。
- 主动申请 7 天内有效，盟主/有权限的职位在 `/union audit` 里处理。
- 退出或被踢后重新加入没有额外冷却。

## 7.3 职位与权限

新建联盟默认有两个职位：

| 职位 | 默认权限 |
| --- | --- |
| 盟主 | 管理成员、创建/管理联盟领地、设置旗标、购买额度、管理金库 |
| 成员 | 进入联盟领地、建造、使用容器、骑乘、传送 |

盟主可以用 `/union rank` 打开职位管理界面，自建职位并分配权限。默认成员在联盟领地内可以建造和使用容器；如果不想让所有成员都能动，需调整职位权限。

同联盟成员之间默认不能互相攻击（服务器固定开启），盟主不能通过职位关闭；该保护只对联盟内成员生效。

## 7.4 联盟金库

```text
/union account                  打开金库界面
/union account balance          查看余额
/union account deposit <金额>   从个人余额存入
/union account withdraw <金额>  从金库取到个人余额（需取款权限）
/union account log              查看流水
```

- 金库是独立的联盟资金，不属于任何个人。
- 创建联盟的 64 钻石**不会**进入金库。
- 联盟领地扩容从金库扣款。
- 联盟领地的规则与命令见 [8. 联盟领地](/union-claims)。
- 取款权限由职位控制；默认盟主可操作。

## 7.5 联盟聊天

```text
/union chat <消息>
```

也可以 `/channel Union` 切换到联盟频道，再直接发言。联盟频道只有同联盟成员可见。

## 7.6 成员管理

```text
/union kick <玩家>            踢出成员
/union ban <玩家> [原因]      封禁成员
/union unban <玩家>           解除封禁
/union transfer <玩家>        转让盟主
/union leave                  退出联盟
/union disband                解散联盟
/union rename <新名>        改名
/union rank                   职位管理
```

`/union leave`、`/union disband` 等操作需要二次确认；按提示在 5 秒内输入 `/union confirm`。
