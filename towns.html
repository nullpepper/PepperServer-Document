联盟

联盟是服务器团队玩法的核心，允许玩家建立自治团体，共同圈占领地、共享资源。每位玩家只能加入一个联盟，每个联盟有一位盟主。

联盟系统由服务器自研插件 PepperUnion 提供，所有指令以 /union 开头。

创建联盟​

/union create <名字>

输入命令后再次输入 /union confirm 确认（5 秒内有效），即可创建联盟：

  • 创建消耗 64 钻石（从你的余额扣除）。
  • 名字支持中文，最长 24 个字符，不能包含空格。
  • 创建后你自动成为盟主，联盟为 1 级。

加入联盟​

联盟有三种加入策略（由盟主通过 /union config 设置）：

策略说明加入方式
OPEN（开放）任何玩家可直接加入/union join <联盟编号>
APPLY（申请）需要提交申请，由管理成员审核/union apply <联盟编号> <留言>，管理成员用 /union audit 审核
CLOSED（关闭）只能通过邀请加入等待邀请后 /union accept <联盟编号>

邀请成员（需邀请权限）：

/union invite <玩家>

被邀请的玩家输入 /union accept <联盟编号> 即可入盟。邀请有效期为 10 分钟。

查看联盟：

指令作用
/union list查看全部联盟列表
/union info [联盟编号]查看联盟详情（等级、经验、盟主、成员数等；不填编号查看自己的联盟）
/union gui打开联盟图形界面

成员管理​

指令作用权限
/union kick <玩家>踢出成员踢人权限
/union ban <玩家> [原因]拉黑玩家（禁止其再加入）踢人权限
/union unban <玩家>解除拉黑踢人权限
/union leave退出当前联盟（盟主需先转让或解散）本人
/union rank set <玩家> <职位>调整成员职位分配权限

盟主专属​

以下操作仅盟主可以执行：

指令作用
/union transfer <玩家>转让盟主
/union disband解散联盟（需 /union confirm 二次确认）
/union rename <新名字>联盟改名
/union rank create/delete/setperm管理职位定义
/union setitem把手中物品设为联盟头像
/union config set <键> <值>修改联盟配置

联盟配置​

指令作用
/union config list查看当前配置
/union config get <键>查看某项配置
/union config set <键> <值>修改配置

常用配置项：

配置键说明可选值
joinPolicy加入策略OPEN / APPLY / CLOSED
announcement联盟公告任意文本
defaultRank新成员默认职位职位 ID
avatar联盟头像物品用 /union setitem 设置

联盟账户​

联盟拥有独立的金库账户，用于存钱、拨款与领地额度购买。

指令作用权限
/union account balance查看账户余额所有人
/union account deposit <金额>存入钻石存款权限
/union account withdraw <金额>取出钻石取款权限
/union account give <玩家> <金额>拨款给成员拨款权限
/union account log [条数]查看账户流水流水权限
/union logs [条数]查看联盟操作日志视权限

联盟聊天​

指令作用
/union chat <消息>向联盟成员发送内部消息

等级与经验​

联盟通过积累经验升级，等级越高成员上限越多：

等级升级所需累计经验成员上限
1-10
210020
330035
460050
5100070
61500100

经验为累计值，升级不清空。等级最高 10 级（7 级起的累计经验要求为 2100 / 2800 / 3600 / 4500）。

联盟经验通过成员活跃度获得（如领地繁荣度联动上报）。

PvP 保护​

  • 默认情况下，同联盟成员之间无法互相攻击（包括弓箭等远程伤害）。
  • 盟主不受此限制（可通过职位权限 union.pvp.attackAlly / union.pvp.attackedByAlly 为指定职位开放）。

小提示​

  • 忘记命令？随时输入 /union help 查看帮助。
  • 联盟需要成员活跃维护，长时间无人管理的联盟可能被清理。
  • 联盟相关权限体系详见 职位与权限。
