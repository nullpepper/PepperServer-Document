14. 命令速查表 ​

14.1 基础与传送 ​

命令作用
/spawn回主城
/back回上一个位置/死亡点
/warp court主城观景台
/warps公共传送点列表
/tpa <玩家>请求传送到对方
/tpahere <玩家>请求对方传送到你
/tpaccept / /tpyes接受传送请求
/tpdeny / /tpno拒绝传送请求
/tpignore忽略传送请求
/rtp不可用

14.2 传送点 ​

命令作用
/sethome <名字>设置传送点
/home <名字>前往传送点
/home传送点列表
/delhome <名字>删除传送点
/homelist列出传送点
/homes传送点界面
/phome <玩家>.<传送点>访问公开传送点

14.3 经济 ​

命令作用
/balance查看余额
/pay <玩家> <金额>转账
/baltop余额排行
/paytoggle开关接收转账
/bank银行界面
/bank add <数量>存钻石
/bank takeout <数量>取钻石

14.4 个人领地 ​

命令作用
/pclaim领地界面
/pclaim create <名字>金锄选区创建
/pclaim info [领地]领地信息
/pclaim list领地列表
/pclaim rename <领地> <新名>领地改名
/pclaim select <领地>选中领地范围
/pclaim quota额度
/pclaim buy <格数>购买额度
/pclaim expand <格数> [方向]扩边
/pclaim resize <领地>重划
/pclaim set flag <领地> <旗标> <值>领地级旗标
/pclaim group <领地> list查看成员组
/pclaim group <领地> create <组名>新建成员组
/pclaim group <领地> assign <玩家> <组名> [时长]把玩家加入组
/pclaim group <领地> unassign <玩家>移出成员组
/pclaim group <领地> setflag <组> <旗标> <值>设置组权限
/pclaim group <领地> delete <组名>删除成员组
/pclaim ban <玩家> [领地]禁止某人进入/使用领地
/pclaim unban <玩家> [领地]解除封禁
/pclaim settp设置领地传送点
/pclaim home回自己的领地
/pclaim home transfer <玩家>转让
/pclaim home accept接受转让
/pclaim delete <领地>删除
/pclaim map打开领地地图
/pclaim borders显示领地边界
/pclaim trapped脱困
/pclaim gui图形界面
/pclaim help游戏内帮助

14.5 联盟 ​

命令作用
/union联盟界面
/union create <名字>创建（64 钻石）
/union confirm二次确认
/union invite <玩家>邀请
/union accept <联盟编号>接受邀请
/union join <联盟编号> [留言]申请加入（apply 为别名）
/union audit申请审核界面
/union info [联盟编号]联盟信息
/union list联盟列表与编号
/union chat <消息>联盟频道
/union account金库
/union account deposit <金额>从个人余额存入联盟金库
/union account withdraw <金额>从联盟金库取到个人余额
/union rank职位管理
/union kick <玩家>踢人
/union ban <玩家> [原因]封禁成员
/union unban <玩家>解除封禁
/union transfer <玩家>转让盟主
/union leave退出
/union disband解散
/union rename <新名>改名
/union help帮助
